# 📖 Portal Organizados

Sistema de gestão para congregações das Testemunhas de Jeová.

## 🚀 Tecnologias

### Frontend
- React 18.2.0
- TypeScript 5.2.2
- Vite 5.0.8
- Tailwind CSS 3.3.6
- Lucide React (Ícones)
- React Router DOM 7.18.3

### Backend
- Node.js 18.x
- Express 4.18.2
- Prisma (ORM)
- PostgreSQL 15+
- JWT (Autenticação)
- Bcryptjs (Senhas)

### Mapas
- Google My Maps
- Leaflet 1.9.4
