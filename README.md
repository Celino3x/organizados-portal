# Portal Organizados

Sistema de gestão para congregações das Testemunhas de Jeová.

## 🚀 Funcionalidades

- 👥 **Congregação**: Gerenciamento de publicadores com níveis de acesso
- 🗺️ **Territórios**: Mapa interativo com Google My Maps
- 📋 **Designações**: Agendamento e gerenciamento de designações
- 📊 **Relatórios**: Estatísticas e relatórios da congregação
- 🌓 **Tema Escuro**: Suporte a tema claro/escuro
- 📱 **Responsivo**: Funciona em PC, Tablet e Celular

## 🛠️ Tecnologias

- **Frontend**: React + TypeScript + Tailwind CSS
- **Backend**: Node.js + Express
- **Banco de Dados**: MongoDB Atlas
- **Mapas**: Google My Maps / Leaflet
